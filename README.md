# 🦆 Duck-Shop

Duck-Shop é um **modelo de e-commerce funcional** desenvolvido como projeto de portfólio. Inspirado e estruturado a partir do **modelo da Void Studio**, ele foi construído para demonstrar habilidades em **front-end**, **animações interativas**, **estrutura de produto** e **experiência do usuário**.

---

## 🌟 Sobre o Projeto

Este projeto serve como um exemplo de como um e-commerce pode ser estruturado de forma simples, elegante e funcional. Ele inclui:

- Catálogo de produtos (com imagens e descrições detalhadas)
- Carrinho de compras interativo
- Layout responsivo, otimizado para desktop e mobile
- Animações sutis e interativas para melhorar a experiência do usuário
- Estrutura limpa e modular, seguindo boas práticas de desenvolvimento front-end

> O Duck-Shop é inspirado no modelo de e-commerce produzido pela **Void Studio**, conhecido por criar interfaces modernas e intuitivas para lojas online. O projeto replica a lógica de organização de produtos, navegação e layout responsivo, oferecendo uma base prática para quem deseja aprender ou demonstrar habilidades em desenvolvimento web.

---

## 🛠 Tecnologias Utilizadas

- **HTML5** e **CSS3** para estrutura e estilos
- **JavaScript** para interatividade e animações
- **GSAP** para animações avançadas e efeitos visuais
- Estrutura modular e sem frameworks pesados, facilitando personalizações futuras

## 🚀 Funcionalidades

- Navegação simples e intuitiva
- Adição e remoção de produtos do carrinho
- Animações responsivas para interações do usuário
- Layout adaptável a diferentes tamanhos de tela
- Base prática para quem deseja criar ou personalizar um e-commerce

---

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido para:

- Servir como **portfólio profissional**
- Demonstrar **habilidades em front-end** e manipulação de DOM
- Oferecer uma base sólida para criar **e-commerces mais complexos**
- Inspirar outros desenvolvedores a explorar **interatividade e UX**

---

## 📌 Observações

- Projeto puramente front-end, sem integração real com pagamento ou banco de dados
- Ideal para estudo, demonstração de habilidades e aprendizado prático
